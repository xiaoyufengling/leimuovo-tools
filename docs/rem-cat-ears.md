# 蕾姆猫耳（Rem Cat Ears）

“蕾姆猫耳”是小鱼个人网站的长期视觉彩蛋，也是可以重复使用的个人标志元素。

## 核心识别

- 名称：蕾姆猫耳
- 英文标识：Rem Cat Ears
- 气质：柔软、短毛、冰蓝、克制，不做夸张萌系装饰
- 主色：雾白与蕾姆冰蓝
- 内耳点缀：低饱和柔粉
- 材质：半透明液态玻璃与细腻短绒感
- 默认反馈：点击后轻轻抖动，并出现小型“喵~”气泡

## 使用原则

1. 猫耳应作为小彩蛋存在，不能抢过页面标题和作品内容。
2. 优先放在“小鱼”名称、头像或个人署名的正上方。
3. 气泡必须小巧，不使用大弹窗、遮罩或强提示音。
4. 不在界面中解释蕾姆设定；用冰蓝、柔粉与材质暗示个人偏好。
5. 保留键盘焦点、按钮语义和减少动态效果支持。

## 项目实现

- 独立模块：`apps/web/src/components/RemCatEars.astro`
- 视觉实现：`apps/web/src/styles/home.css`
- 交互实现：`apps/web/public/scripts/site.js`
- 当前调用位置：`apps/web/src/components/SiteHeader.astro`

模块的调用接口只包含无障碍名称与提示文字。默认提示为“喵~”，视觉结构由模块内部统一维护。
