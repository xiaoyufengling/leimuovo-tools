# Leimuovo Design System

本文档是 Design System 的使用说明；可执行真源位于 `packages/design-system/src`。

## 原则

1. 内容优先：装饰不能抢走工具本身的注意力。
2. 安静克制：仅用黑白灰和系统蓝，不使用复杂渐变、滚动劫持或装饰性动效。
3. 一致可预期：同一种操作使用相同的控件、反馈和措辞。
4. 本机优先：涉及文件的界面必须明确说明处理位置和网络行为。
5. 无障碍默认：正文对比度至少 4.5:1、触控目标至少 44×44px、键盘功能完整。

## Tokens

- 颜色、字体、间距、圆角、阴影、动效和布局宽度全部使用 `--lm-*` tokens。
- 禁止在业务页面直接写品牌色十六进制值。
- 浅色和深色模式使用同一语义 token，不在页面内单独维护主题选择器。
- 状态不能只靠颜色区分，必须同时提供图标或文字。

## 排版

- 系统字体栈，不加载第三方 Web Font。
- 正文默认 16px、行高 1.65；说明文字最低 12px。
- 首页标题使用 `--lm-text-display`，上限 64px；工具标题使用 32px 或 24px。
- 正文阅读宽度不超过 720px。

## 控件

- 主按钮用于每个视图最重要的动作；同一区域最多一个主按钮。
- 次按钮、图标按钮、输入框分别使用 `.lm-button--secondary`、`.lm-icon-button`、`.lm-input`。
- 图标统一使用 Lucide，常规尺寸 16/20/24px，描边 1.75px；不使用 Emoji 代替图标。
- 卡片默认不可点击；只有完整卡片确实是链接时才提供整体 hover 与焦点状态。

## 动效

- 仅动画 `opacity` 和 `transform`，持续时间使用 120/180/240ms tokens。
- 进入使用统一标准缓动，离开可以更快；不使用无限循环动画。
- `prefers-reduced-motion` 下停用非必要动画。

## 响应式

- 移动优先，检查 390、768、1024、1440px。
- 断点：480、768、1024、1280px；卡片网格使用弹性列，不为工具数量写死布局。
- 任何主要操作都不能依赖 hover，手机端不得出现横向页面滚动。

## 新工具接入

新工具必须使用 ToolShell、目录元数据接口和共享 tokens。需要复杂客户端状态时先使用原生 TypeScript；只有当 React 能显著降低该工具内部复杂度时才增加 Astro React island，不能把站点外壳迁入 React。
